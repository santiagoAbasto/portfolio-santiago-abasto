## 2. Cómo cambiar la miniatura de un enlace

**Si LinkedIn deja reemplazar la imagen:**

1. Perfil → **Proyectos** → lápiz del proyecto.
2. En **Multimedia**, lápiz sobre el elemento.
3. En **Vista en miniatura**, lápiz → subir el PNG de 1200 × 630 indicado abajo → aplicar.
4. Revisar título y descripción → **Aplicar** → **Guardar** en el proyecto.

**Si no deja reemplazarla:**

1. Confirmar que la URL, el título y la descripción del elemento están en el inventario.
2. Lápiz sobre el elemento → **Eliminar**.
3. **Añadir multimedia → Añadir un enlace** → pegar la URL de esta guía → **Añadir**.
4. Lápiz sobre la vista previa → subir el PNG → completar título y descripción → **Aplicar** → **Guardar**.

> [!WARNING]
> Subir una imagen como «multimedia» **no** la convierte en un enlace clicable. Agregá siempre un **enlace** y después cambiá su miniatura.

Dejá **A primero y B segundo** (se pueden reordenar arrastrando). Usá los PNG de **1200 × 630**, la proporción de las vistas previas de enlaces; los de 1200 × 675 quedan para el README y otras publicaciones.
